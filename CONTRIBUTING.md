# Contributing to CareerLens AI

Thank you for your interest in contributing to **CareerLens AI**! We welcome contributions from the community to help make career intelligence accessible, accurate, and transparent.

## How to Contribute

### 1. Reporting Bugs
- Check existing issues before submitting a new report.
- Include OS version, browser, steps to reproduce, and expected vs actual behavior.

### 2. Suggesting Enhancements
- Open a feature request issue describing the use case and proposed solution.

### 3. Code Contributions
1. Fork the repository and create a feature branch (`git checkout -b feature/my-feature`).
2. Follow existing code formatting conventions (PEP 8 for Python backend, Standard JS/React patterns for frontend).
3. Ensure all tests pass (`pytest` for backend, `npm run build` for frontend).
4. Submit a Pull Request targeting `main` with a detailed description of your changes.

## Security Disclosures
For security vulnerabilities, please do **NOT** open a public issue. See [SECURITY.md](SECURITY.md) for private reporting instructions.
