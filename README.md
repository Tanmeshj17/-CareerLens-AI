## 🌐 Deploying to Production (e.g. Render.com)

Render can automatically deploy this monorepo via the `render.yaml` blueprint:
1. Push this repository to GitHub.
2. Link the repository to your Render account.
3. Render will provision the PostgreSQL database, FastAPI backend, and React frontend static site automatically.
